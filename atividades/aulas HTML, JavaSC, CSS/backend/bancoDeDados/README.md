# Controle de inventario
## projeto de inventario, com registros mantidos de forma manual.
## para rodar nescessita dos arquivos do projeto, junto do node_modules.
## tecnologias utilizadas: 
### vscode, Thunder Client, git(envio).
## rotas:
### get(mostrar), post(novo item), delete(apagar item), put(alterar item).
## exemplo de requisições:
### id, unidade, kg, precoUnitario, quantidade.
## exemplos de resposta:
### ex: delete id 1: apaga o id 1.
